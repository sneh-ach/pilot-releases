# Pilot releases

Public Mac and Windows installers for Pilot Desktop, plus `latest.json` for the in-app updater.

Source is private. Pairing is not on the internet. This repository is files only.

Until a release is published, there is nothing to download. Unsigned builds: on a Mac, right-click Open the first time. On Windows, SmartScreen may warn.

Site: https://present-freely.vercel.app
