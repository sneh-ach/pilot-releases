# Security

This repository is **public installers only**. Pairing never uses GitHub.

## Do not send here

A pairing PIN, a session URL (`192.168…` or `/c/…`), speaker notes, a deck, or a screenshot of a live QR. Those belong on the two devices in the room. Publishing them would let someone else join that session.

## What a published installer is

A desktop app you run on the computer that has the slides. The phone opens a page that computer serves on the local network. This repository cannot see a session.

The in-app updater may fetch `latest.json` from Releases. That file is an installer pointer. It is not pairing.

## Reporting

Use [Contact](https://present-freely.vercel.app/contact) on the site.

If no inbox is published yet, that page will say so instead of pretending a message was sent. Do not file an issue here — the tracker is off so pairing details do not land in public tickets.
